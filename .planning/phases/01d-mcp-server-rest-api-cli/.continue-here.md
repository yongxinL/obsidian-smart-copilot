| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| pytest-asyncio subprocess logging | pytest-asyncio session-scoped event loop corrupts Python's logging module for subprocess.run() children | blocking | MCP stdio tests run via standalone subprocess, not pytest-asyncio; skip markers on subprocess tests under pytest |
| ENG-302 session_with_rls engine binding | async_session_factory bound at module import time to production localhost:5432 engine | advisory | Tests must patch BOTH _db_mod.async_session_factory AND _orig_swsrl.__globals__["async_session_factory"] |
| nested event loop conflict | asyncio.run() + anyio.run() nesting causes "Already running asyncio in this thread" | advisory | Single anyio.run(_lifecycle) for entire stdio lifecycle; thread-offload at top-level guard only |
